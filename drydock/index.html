TACTICAL GEOMETRY / SIX-FACE PROFILE
Weapon arc reference
Relative to the ship’s bow, not the screen. Faces number clockwise: 1 forward-port, 2 forward, 3 forward-starboard, 4 aft-starboard, 5 aft, 6 aft-port. Each face is a 60° sector; the same numbering identifies shields.
ArcFacesEngine code
Port and starboard cover two sectors (120°), not 180°. Bow and stern turrets cover five sectors (300°), omitting aft-only and forward-only respectively. They overlap on faces 1, 3, 4 and 6.
Named presets define coverage, not weapon type or physical location. An installation may use a custom face set. This reference does not alter any stock ship’s arcs.
