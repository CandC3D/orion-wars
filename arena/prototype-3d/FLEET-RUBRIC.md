# Complete-library contact sheets — rubric before implementation

Each hull and each faction sheet must score at least 90 independently. Direct
inspection of the rendered views is mandatory. A failed faction is withheld;
successful factions may be delivered separately. Pending fighter/flagship codes
are explicit authorised blanks, not guessed fiction. Planning rim-code reading
remains the already measured failure, outside this inspection-scale gate.

| Hull criterion | Weight | Evidence / failure condition |
|---|---:|---|
| Authored geometry and colour regions | 30% | Validated faction palette, every component/region retained, measured reduction error, actual source geometry and available schematics inspected; no invented anatomy or colour remapping. |
| Period paint and metals | 30% | All requested metals read as rough metallic paint; actual recess wash and raised-edge brushwork; dead-flat Krelath decks; painted Vraygon green; inert bright regions. No chrome or smooth plastic body. |
| Miniature, scale and mounting | 20% | Explicit source calibration and provisional shared ladder; true measured model size, black FASA base and tapered 30 mm exposed post seated on actual underside. |
| Inspection and identification | 20% | Same view pair, unclipped silhouette/stand, readable supplied rim code in close side view, honest name/type/code caption. Both distinct flagships identified by full filename and differences explained. |

| Sheet criterion | Weight | Evidence / failure condition |
|---|---:|---|
| Completeness and authority | 30% | Every non-composite GLB in the three named libraries exactly once; explicit code table entries including pending blanks, no Zandrax; no missing/merged flagship. |
| Direct visual comparison | 30% | Consistent views/light/material treatment, clear captions, all hulls inspectable, each hull passes its own gate. |
| Provisional scale strip | 25% | Every hull at one shared physical scale with no per-object fitting in the strip; lengths/calibration/assumptions published, no claim that the class ladder is settled. |
| Reproduction and scope | 15% | Source hashes unchanged, reproducible derivatives and manifests, tests and browser evidence; only prototype files, furniture unchanged, no shared runtime/branch/commit. |

Unscored outside this slice: native full-board recognition/performance, facing,
clear-plastic adoption, destruction, planets/nebulae, Zandrax and permanent intake.
Uncertain source scale/anatomy is reported, never silently inferred as canon.
